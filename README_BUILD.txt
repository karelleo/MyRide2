MY RIDE ANDROID - PROJECT APK

Isi:
- Aplikasi Android wrapper WebView untuk prototype My Ride v2.
- UI Beranda dan Aktivitas dari HTML prototype.
- Data dan lampiran menggunakan IndexedDB WebView pada perangkat.
- File upload foto/PDF melalui pemilih file Android.
- Nama file download menggunakan ID nota.

CARA BUILD APK:
1. Extract MyRideAndroid.zip.
2. Buka Android Studio.
3. Pilih Open, lalu pilih folder MyRideAndroid.
4. Tunggu Gradle Sync. Gunakan JDK 17 atau 21 dan Android SDK Platform 35.
5. Pilih Build > Build Bundle(s) / APK(s) > Build APK(s).
6. APK debug berada di app/build/outputs/apk/debug/app-debug.apk.

CATATAN:
- Proyek ini belum dikompilasi menjadi APK di lingkungan ini karena Android SDK/Build Tools tidak tersedia.
- Ini prototipe UI/UX dan penyimpanan lokal berbasis WebView/IndexedDB, bukan aplikasi resmi Gojek.
- OCR otomatis belum diaktifkan.
